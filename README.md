# Metall Turbo product images

Product photos for the Metall Turbo price list. Each file is linked from the **Images** column of the `Products` sheet and read by the n8n Instagram automation.

Direct link format:

    https://raw.githubusercontent.com/userAbdullo-h/metall-turbo-images/main/<file>.jpg

File names are `<sheet>-t<table number>.jpg` (sheet name transliterated), e.g. `ventil-t03.jpg` = sheet "вентил", table 3.
